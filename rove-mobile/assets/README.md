The supplied Rove Asset Library v2 is organized here. See `../ASSET_INVENTORY.md`
for each file's status and intended use. The original artwork bytes and filenames
are preserved. Discover uses only the approved original mascot; the other
imported graphics are not rendered by the app.

`branding/` contains a traced wordmark that still requires silhouette approval.
`mascot/` contains the approved original explorer and an exact alpha crop.
`icons/provisional/` contains unapproved candidates. `references/` contains
flattened design guidance, never functional screens. `tokens/` contains the
archive's approximate, provisional values.
