The supplied Rove Asset Library v2 is organized here. See `../ASSET_INVENTORY.md`
for each file's status and intended use. The original artwork bytes and filenames
are preserved. Discover uses the approved original mascot. Milestone 2.1
renders five provisional icon paths in the navigation and location field,
while retaining their original SVG files and provisional status.

`branding/` contains the existing traced wordmark, explicitly approved by the owner in Milestone 3A. Its SVG is locked; `src/components/BrandWordmark.tsx` renders the exact path on Android and web.
`mascot/` contains the approved original explorer and an exact alpha crop.
`icons/provisional/` contains unapproved candidates. `references/` contains
flattened design guidance, never functional screens. `tokens/` contains the
archive's approximate, provisional values. `demo/` contains separate CC0 sample place photographs with sources and usage details in `demo/README.md`.
